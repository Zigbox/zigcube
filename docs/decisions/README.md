# Decisions

One file per lasting decision, named `YYYY-MM-DD-<slug>.md`, so two branches that each record a decision never edit the same file. List the folder to read them; the names sort by date. There is no index to keep in step.

Each file has a title line, `*Decided <date>, by <who>.*` (owner, supervisor, or the slice), the decision and its reasons, and `Where:` naming the docs that carry the detail. A decision is never edited once merged: a new file supersedes it and says which file it replaces.

Entries before 2026-11-03 were split out of the old single `docs/DECISIONS.md`, which is kept as a pointer so references to it still resolve.
