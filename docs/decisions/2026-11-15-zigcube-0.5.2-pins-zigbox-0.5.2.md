# Zigcube's B4–B7 release is 0.5.2, pinning Zigbox v0.5.2

*Decided 2026-11-15, by the owner (relayed by the supervisor).*

Supersedes the version row and the pin paragraph of
`2026-11-14-zigcube-versions-follow-zigbox.md`. The rest of that file (one source for the version,
placeholders, versions follow Zigbox) stands.

| Zigcube release | Milestones | Version | Tag |
|-----------------|------------|---------|-----|
| b7 | B4–B7 | 0.5.2 | `v0.5.2` |

- **Why not 0.5.1.** B4 slice 4 needs Zigbox's egress S3 work (ZBX-E0610, ZBX-E0611, ZBX-E0612),
  which ships in Zigbox 0.5.2, not 0.5.1. Zigcube's version follows the Zigbox it pins, so the
  bundle ships as 0.5.2 once it pins Zigbox v0.5.2. There is no Zigcube v0.5.1 tag.
- **What changes after the merge of the bundle (#258, `ad4c6ca`):** `.version` in `build.zig.zon`
  becomes 0.5.2, the `zigbox` pin moves to the v0.5.2 tag, and B4 slice 4 lands.

Where: `build.zig.zon`, `docs/releases/b4-b7.md`.
