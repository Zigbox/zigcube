# B2 retro

B2 was the hardening release: B1's release-review findings, the simulation fleet's issues, renewal before fence, and a stronger simulator (wiped disks, unplaceable jobs, seeded fault profiles). It was tagged `b2` at main 97cd643 on 2026-11-11 with every CI job green on that commit. The two release reviews' MUSTs were fixed in #201, #203 and #204.

## What was off

- **The J6 fix was assumed done when its seed passed.** #142's fix enforced deadlines only between steps, so seed 102 found a run that overstayed its deadline mid-step after the release reviews had finished. #142 was reopened, and the tag waited about a day for #212 (a call floor, then a re-review). Change: a deadline fix gets a test that holds a step past the deadline, not only a replayed seed.
- **A tooth was assumed to fit in the release.** `job_reuse` did not converge in time. The owner accepted shipping without it (`docs/decisions/2026-11-09-b2-ships-without-job-reuse.md`). Change: a brief lists its teeth as cuttable unless the release depends on them.
- **The 24-hour fleet soak was assumed to fit the schedule.** It did not. The owner waived it, because B2 is the hardening release whose own fixes the soak would test. Change: none to the rule; the next release that ships features runs the soak.
- **Sessions lost unpushed work** when containers were reclaimed. Change: push about every 10 minutes, and open no pull request before the work is ready (AGENTS.md, Git).

## What moves on

The reviews' SHOULDs and NITs, and the two NITs from #212's re-review (no test reaches the lost update in `Work.running`; a failed `runtime.stop` in `enforce_one` leaves the wake unset), go to B2.1.
