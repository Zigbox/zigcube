# C1 slice 5: `sim-c1`

Brief from the supervisor, with the gap table the implementer filled in first. Sources:
`docs/authority.md` §4 (invariants, negative tests) and §5 (acceptance test), `docs/core.md`
("The cluster simulation").

## The brief

`zig build sim-c1 [-Dseed=N] [-Dops=N]` checks I1a–I7 after every event under the listed faults,
proves its three negative tests find violations, runs §5's acceptance test over every decision a
run writes, runs natively and as WASM with byte-identical reports, and runs in `zig build check`
(fresh seed, printed first, like sim-cluster) and in CI.

Build on `sim_cluster`, `sim_checks`, `sim_world`, `sim_net`, `sim_clock`, `sim_node`; do not fork.
Either a mode of sim-cluster plus a runner, or a thin entry over the same world: the smaller wins,
recorded in `docs/DECISIONS.md`.

1. This file, first.
2. Fill the gaps: I1a, I2, I4, I6, I7 against store state at every revision (I4 with the core's
   writer-role table); I1b needs the simulated runtime's physical execution intervals per replica
   instance (overlap within `lost_grace_ms` + kill latency when skew is within bound and the node
   is not wedged; a wedged node records the overlap, no failure for stateless replicas); I3 every
   decision's cited observation was admissible at its cited revision; I5 every `why` is complete
   or names its truncation. Duplicates must now fail: fix real core bugs with a regression test,
   or stop and report if the fix is large.
3. Negative tests, each passing only if the check fails (like sim-teeth), test-only switches
   unreachable in release builds: skew beyond bound / a wedged node breaks I1b; a scheduler that
   skips the allocation compare breaks I6; one that skips the readiness compare, with a node lost
   between planning and commit, breaks I7.
4. Acceptance test (§5), in sim-c1 and as a `zig build test` test over the real core.
5. Native and WASM report bytes identical.
6. Docs: `docs/core.md` section; AGENTS.md Commands line; `zig build check`'s PASS line names
   sim-c1; a CI job.

Done when: `zig build sim-c1` passes on fresh seeds and a seed range (1..200) through the native
runner; the three negative tests and the acceptance test pass; `zig build check` is PASS.
