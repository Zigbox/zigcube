Diagnostic code

ZC-E0115

can't write the output

Kind
error
Blame
environment
Exit code
2

What it means

zcube could not write its result to standard output or standard error: the descriptor is closed, the pipe has no reader, or the disk is full (for example when redirected to /dev/full). The command itself may have succeeded: an apply is not undone by this failure.

Run it again with output that can be written, or check with zcube get.
