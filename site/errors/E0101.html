ZC-E0101

no such resource

Kind
error

user
Exit code
1

What it means

The API was asked for a service, replica or node that does not exist, or for a path it does not serve. Nothing was changed.

List what exists with zcube get service, or check the name for a typo. A deleted service keeps its decision history for a day, so zcube why can still explain a recent deletion.
