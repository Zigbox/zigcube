# Zigcube

Orchestrator for Zigbox workloads, written in Zig. Pre-alpha.

- Start with `HANDOFF.md`: current scope, the `Store` and `Runtime` contracts, milestone demos, and what to ask the human before doing.
- Every failure path follows `DIAGNOSTICS.md` (shared with Zigbox; change both copies together).
- The project website is `site/index.html`; milestone status and demo output live in the data objects at the top of its script.
- Commits: small, signed off (`git commit -s`), Apache 2.0.
